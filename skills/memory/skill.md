# Memory Skill

This skill enables searching through past threads and conversations.

## Usage

Invoke this skill when users need to:
- Recall prior decisions or solutions
- Find earlier work on a similar problem
- Recover project context from previous threads

## Process

1. Build a focused recall query.
2. Search past threads.
3. Rank and summarize relevant matches.
4. Return concise context and references.

## Output Format

- Relevant thread list
- Matching snippets
- Suggested next action based on recalled context

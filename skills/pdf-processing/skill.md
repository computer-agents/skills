# PDF Processing Skill

This skill enables comprehensive PDF manipulation.

## Usage

Invoke this skill when users need to:
- Extract text/tables from PDFs
- Merge/split documents
- Fill forms or create PDFs
- Run OCR for scanned PDFs

## Process

1. Determine operation type.
2. Select toolchain (Python libs / CLI tools).
3. Execute transformation.
4. Validate and return output artifacts.

## Output Format

- Processed PDF files
- Extracted structured output (text/JSON/table)
- Validation status

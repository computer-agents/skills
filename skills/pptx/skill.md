# PPTX Skill

This skill enables PowerPoint presentation creation, editing, and analysis.

## Usage

Invoke this skill to:
- Create new presentations from scratch
- Edit existing decks
- Apply template-driven replacements
- Extract slide text/inventory

## Process

1. Choose workflow (HTML2PPTX, template, OOXML edit).
2. Apply scripted transformation.
3. Validate output (e.g. thumbnails/inventory).
4. Return final deck + change summary.

## Output Format

- Updated `.pptx` file
- Optional inventory/validation output
- Change log of slide operations

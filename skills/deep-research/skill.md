# Deep Research Skill

This skill enables comprehensive research capabilities using Gemini's Deep Research API.

## Usage

Invoke this skill when the user asks for:
- In-depth research on a topic
- Comprehensive analysis requiring multiple sources
- Fact-checking with citations

## Process

1. Analyze research question and constraints.
2. Gather relevant sources across perspectives.
3. Synthesize findings with confidence levels.
4. Produce structured report with references.

## Output Format

- Research summary
- Key findings
- Evidence table
- Source citations

# Image Generation Skill

This skill enables AI-powered image generation and editing.

## Usage

Invoke this skill to:
- Generate images from text
- Create variants from references
- Produce concept visuals quickly

## Process

1. Refine prompt for visual clarity.
2. Select style and size parameters.
3. Generate image.
4. Return saved output + prompt metadata.

## Output Format

- Generated image artifact
- Prompt used
- Key generation parameters

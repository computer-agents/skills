# Web Search Skill

This skill provides real-time web search capabilities.

## Usage

Invoke this skill when users need:
- Current information from the web
- Fast fact checks
- News and recent updates

## Process

1. Formulate and optimize query.
2. Execute search and collect top results.
3. Filter by relevance and recency.
4. Return summary and sources.

## Output Format

- Search summary
- Source links and titles
- Key extracted facts
